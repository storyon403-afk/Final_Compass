贵州大学（Guizhou University，简称"贵大"）简介：

【基本概况】
贵州大学位于贵州省贵阳市，是教育部与贵州省人民政府"部省合建"高校，国家"双一流"建设高校、"211工程"重点建设高校，也是贵州省高等教育的"排头兵"，扎根贵州大地办学，以服务贵州区域经济社会发展为使命。

【历史沿革】
- 学校源头可追溯至1735年创建的贵山书院
- 1902年，贵州巡抚邓华熙奏请设立贵州大学堂，此为建校之始，后改名"贵州高等学堂"
- 历经贵州大学堂、省立贵州大学、国立贵州农工学院、国立贵州大学等时期
- 1942年，行政院决议归并国立贵州农工学院，成立国立贵州大学
- 1950年10月定名为贵州大学
- 1951年11月，毛泽东主席亲笔题写"贵州大学"校名
- 1997年8月合并组建新的贵州大学
- 2004年成为省部共建高校

【办学条件】
- 设有40个学院，学科专业涵盖文学、历史学、哲学、理学、工学、农学、医学、经济学、管理学、法学、教育学及艺术学等12大类
- 拥有全国重点实验室1个、省部共建国家重点实验室1个
- 部级以上科研平台26个，省级科研平台55个
- 2022年有项目入选教育部首批虚拟教研室建设试点名单

【学科与科研特色】
作为贵州省唯一的"双一流"建设高校，贵州大学的特色优势学科集中在植物保护（世界一流学科建设学科）、农林、大数据、生态等领域。因为地处西南、相对偏远，考研报考热度不高，但几乎所有专业都是211（现"双一流"）层次，性价比较高。

【知名校友】
百余年来培养了大量扎根贵州、服务西南的各类人才，涵盖农业、工程、教育、管理等多个领域。

【校园环境】
学校坐落在贵阳，主校区位于花溪区花溪大道南段2708号（花溪校区），校园依山傍水，融入喀斯特地貌的自然景观之中，素有"云贵高原上的知识绿洲"之称。

总体而言，贵州大学是一所历史悠久、以农林和区域特色学科见长的综合性大学，是贵州省高等教育的旗舰和最高学府。如果你是想了解报考信息（分数线、专业）、校园生活体验，或者某个具体学院的情况，可以告诉我，我再帮你查详细资料。
