====================
伊雷娜·森德勒（Irena Sendler，1910-2008）
====================

一、基本生平
- 1910年2月15日生于波兰华沙，原名伊雷娜·克日扎诺夫斯卡（Irena Krzyżanowska），父亲是医生、社会主义活动家，因救治伤寒病人（多为穷人、犹太人）感染去世，这影响了她一生。
- 战前她是一名社会工作者、护士，长期从事贫民救济。

二、二战中的壮举
- 纳粹占领波兰后，华沙建立了犹太隔离区（华沙犹太区），数十万犹太人被关押其中，随后被大批送往特雷布林卡等灭绝营。
- 伊雷娜化名「约兰塔」（Jolanta），加入波兰地下抵抗组织，并成为援助犹太人委员会「热戈塔」（Żegota）的核心成员，专门负责救助犹太儿童。
- 她冒着生命危险进入犹太区，以各种方式将约2500名犹太儿童偷运出来：藏在救护车、棺材、麻袋、工具箱里，走下水道、运货手推车等。出区后给孩子伪造基督教身份，安置在波兰家庭、修道院和孤儿院。
- 最关键的一步：她把每个孩子的真实姓名和家庭信息写在纸条上，装进玻璃瓶，埋在朋友家院子里的苹果树下——期望战后能帮孩子找回亲人。这就是著名的「埋在苹果树下的瓶子」（Jars of Hope / Life in a Jar）的故事。

三、被捕与幸存
- 1943年10月，她被盖世太保逮捕，遭受严刑拷打，双腿和双脚被打断，被判死刑。热戈塔成员贿赂德国军官，使她在行刑途中获救逃脱；此后她隐姓埋名继续从事救助工作。
- 战后她挖出瓶子，试图让孩子们与亲人团聚——但绝大多数孩子的父母已死于集中营，很多孩子从此留在收养家庭。

四、荣誉与晚年
- 1965年，以色列大屠杀纪念馆（Yad Vashem）授予她「国际义人」（Righteous Among the Nations）称号。
- 2003年，波兰授予她最高国家勋章「白鹰勋章」。
- 2007年，波兰政府推动她获得诺贝尔和平奖提名（当年获奖者为美国前副总统戈尔），一度引发广泛关注；她的故事当年在波兰媒体上广为流传。
- 1999年起，美国堪萨斯州一所中学的四名女生因「生活在一罐子里」（Life in a Jar）课题项目走访并戏剧化呈现她的故事，使她在国际上广为人知。
- 2008年5月12日在华沙逝世，享年98岁。

五、名言
- 「我什么都没做，我只是做了我该做的事。」
- 「这个世界可以因一个人而改变。一个人，确实可以。我并不是英雄——我只是个普通人，但普通人也能做出非凡的事。」

总结：伊雷娜·森德勒是二战期间救助犹太儿童数量最多的波兰人之一，被誉为「犹太区里的安徒生」。她一生低调，坚称自己只是做了分内之事，却在历史最黑暗的时刻守护了约2500条幼小的生命。
