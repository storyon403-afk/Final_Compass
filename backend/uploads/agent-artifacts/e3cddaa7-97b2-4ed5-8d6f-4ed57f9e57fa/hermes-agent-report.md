关于"伊雷娜"这个名字,最可能对应的是日本轻小说/动画《魔女之旅》(魔女の旅々,作者:白石定规)的女主角伊蕾娜(Elaina)。需要先澄清一个称呼问题:她严格来说是"魔女"(Witch),不是"魔法少女"(Magical Girl)——不过国内观众常把两者混着叫,如果你说的就是她,以下是简介:

一、基本设定
- 名字:伊蕾娜(イレイナ, Elaina),中文圈也译作"伊雷娜""爱莲娜"等
- 身份:《魔女之旅》的女主角,一名金发、留着齐刘海、气质优雅的年轻魔女
- 设定:15岁便以史上最年轻的身份通过魔法使"最高阶"考核,获得"魔女"称号,随后离开国家,踏上环游世界的旅途

二、人物特点
1. 天才魔法使:自幼天赋极高,在家严格教育下快速成长,被誉为"天才中的天才",但本人并不喜欢别人强调这点。
2. 自称"美丽的我":标志性口头禅,自信(甚至自恋),总以"像我这样美丽的魔女"自称,性格略带傲娇和小恶魔气质。
3. 性格矛盾又真实:表面优雅得体、举止淑女,内心其实怕麻烦、有点自私、偶尔腹黑,会吐槽别人也会自我吐槽。她不是传统意义上善良热血的英雄,更像一个"有点小坏的真实少女",这也是角色人气高的原因。
4. 经历沉重:幼年时读了魔法使"妮可"的冒险传记而憧憬旅行;旅途中见过许多悲剧与人性阴暗面,但她选择继续前行,故事基调介于治愈与致郁之间。

三、作品背景
- 《魔女之旅》是轻小说(2014年起连载),后被改编为漫画、动画(2020年10月播出的TV动画),动画由C2C制作。
- 故事是单元剧结构:每集伊蕾娜到达一个国家,遇到不同的人和故事,很多篇章带有反转、讽刺或悲伤色彩,因此被观众调侃为"致郁之旅"。
- 作品中她与"妮可"的真实关系、自身过去的谜团是主线暗线之一。

四、与"魔法少女"称呼的差异
魔法少女通常指"变身系"少女英雄(如《美少女战士》《魔法少女小圆》式设定),而伊蕾娜是"天生/后天学习魔法的魔女",没有变身、没有契约、没有伙伴精灵,世界观也更偏向奇幻游记而非战斗番。所以如果是在严格区分,应称她为"魔女"而非"魔法少女"。
