2. Controller层规范

POST /api/ai/invoke

Request:

{
 skillId,
 input,
 provider,
 credentialSource
}


Response:

{
 taskId,
 traceId,
 status,
 result
}
Controller只负责：
  • 参数校验
  • 权限检查
  • 调用业务服务
不允许：
  • 直接调用模型
  • 处理Prompt
  • 选择Skill

5. AgentContext设计

class AgentContext {

    UserContext user;

    TaskContext task;

    ConversationContext conversation;

    SecurityContext security;

    Map variables;

}
原则： Context不绑定Skill。 原因： 一个Agent可以连续执行多个Skill。

7. Skill接口

public interface AiSkill {

    String id();


    SkillResult execute(
        SkillContext context
    );

}
Skill负责：
  • 领域能力
  • 输入输出转换
  • 调用工具
Skill不负责：
  • 用户权限
  • 模型选择
  • 数据库事务

12. Hermes接入规范

架构： 
Spring Boot

↓

HermesAdapter

↓

HTTP Client

↓

Hermes Agent Server
Spring不依赖Hermes源码。 只依赖： HTTP协议。 优势：
  • Agent框架可替换
  • Python生态独立
  • 部署隔离
