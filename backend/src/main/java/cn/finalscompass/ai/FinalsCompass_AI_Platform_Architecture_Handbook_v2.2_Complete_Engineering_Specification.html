定位

2. 核心设计原则

  • 业务系统生命周期长，Agent框架变化快，因此必须隔离。
  • Spring Boot 不直接绑定 Hermes、LangGraph 等框架。
  • 通过统一 Agent Runtime 接口实现替换。
  • Skill 表示业务能力，不表示智能主体。
  • Provider Adapter 屏蔽不同模型差异。

4. Agent Runtime设计

4.1 Agent接口

public interface AgentRuntime {

    AgentResponse execute(
        AgentContext context
    );

}

4.2 AgentContext

public class AgentContext {

    UserContext user;

    TaskContext task;

    ConversationContext conversation;

    ExecutionContext execution;

    SecurityContext security;

}
设计原因：
  • Context不直接绑定Skill。
  • Agent可以连续调用多个Skill。
  • 支持未来多Agent协作。

6. Planner与Executor

Planner职责

  • 理解任务。
  • 选择Skill。
  • 生成TaskPlan。
public interface AgentPlanner {

    TaskPlan plan(
        AgentContext context
    );

}

Executor职责

  • 执行计划。
  • 记录步骤。
  • 处理失败和重试。
public interface AgentExecutor {

    ExecutionResult execute(
        TaskPlan plan,
        AgentContext context
    );

}
