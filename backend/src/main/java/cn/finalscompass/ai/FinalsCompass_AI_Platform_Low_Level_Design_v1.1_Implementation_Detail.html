3. AiGateway设计

AI Gateway作为业务系统与Agent系统之间的唯一入口。 

@Service
public class AiGateway {

    private final AgentRuntime runtime;

    public AiResponse invoke(
        AgentRequest request
    ){

        AgentContext context =
            contextFactory.create(request);

        return runtime.execute(context);
    }
}

5. Skill Registry

Skill不通过if-else硬编码，而通过注册机制管理。 

@Component
public class AiSkillRegistry {


    private Map skills;


    public AiSkill get(
        String id
    ){
        return skills.get(id);
    }

}

13. 重构原则

  • AiAnalysisService不继续膨胀。
  • 业务逻辑与AI执行逻辑分离。
  • 模型调用必须经过Provider层。
  • Agent框架必须可替换。
  • 数据库访问统一Repository化。
