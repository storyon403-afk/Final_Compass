8. MySQL核心表

CREATE TABLE ai_task (
 id BIGINT PRIMARY KEY AUTO_INCREMENT,
 user_id BIGINT,
 skill_id VARCHAR(64),
 status VARCHAR(32),
 result TEXT,
 created_at TIMESTAMP,
 updated_at TIMESTAMP
);


CREATE TABLE ai_task_step (
 id BIGINT PRIMARY KEY AUTO_INCREMENT,
 task_id BIGINT,
 step_type VARCHAR(32),
 step_name VARCHAR(128),
 status VARCHAR(32),
 input TEXT,
 output TEXT
);


CREATE TABLE ai_usage_log (
 id BIGINT PRIMARY KEY AUTO_INCREMENT,
 user_id BIGINT,
 provider VARCHAR(64),
 model VARCHAR(128),
 input_tokens INT,
 output_tokens INT,
 cost DECIMAL(10,4)
);

13. 设计结论

Finals Compass AI 平台不直接绑定任何模型或Agent框架。 Spring Boot负责： 业务、安全、权限、任务管理。 Agent Runtime负责： 规划、执行、工具调用。 Provider负责： 模型连接。 因此未来可以替换： Hermes、LangGraph、AutoGen以及其他Agent框架。
