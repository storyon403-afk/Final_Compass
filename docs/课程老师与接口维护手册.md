# 课程、老师与接口维护手册

这份文档用于日常维护“期末指南”。当前页面通过 Java API 读取 MySQL 中的课程和老师；Java 后端未启动时，相关请求会明确失败，不再使用容易与数据库不一致的静态演示数据兜底。

## 1. 添加开场背景图片

把 `.jpg`、`.jpeg`、`.png` 或 `.webp` 图片放进项目的 `apps/web/pictures/` 文件夹，前端会在每次打开页面时随机选择一张。

开场页代码位于：

- `apps/web/src/App.vue`：随机读取图片、点击进入逻辑和开场文字。
- `apps/web/src/styles.css`：开场页遮罩、排版和过渡动画。

现有照片由项目成员及其同学拍摄，并已授权随仓库和应用分发。新增照片仍必须确认版权或取得明确授权，并同步更新 `apps/web/pictures/README.md` 和 `THIRD_PARTY_NOTICES.md`。

## 2. 调试界面数据

课程、老师、资料和讨论都以 MySQL 为唯一业务数据源。调试界面时应启动后端，或在浏览器开发工具中临时模拟接口响应；不要在 `apps/web/src/` 中维护另一套静态业务数据，以免页面效果与服务器实际内容不一致。

## 3. 在 MySQL 中添加课程和老师

管理员账号登录后，可在课程公共面板点击“添加课程”，填写课程名称、代码、所属学院和分类。新增课程会自动归入对应学院。进入课程后还可点击“添加老师”，填写老师姓名和所属学院。普通账号不会显示这些按钮，直接请求接口也会被后端拒绝。

下面的 SQL 方式主要用于批量导入和开发维护。

先确保 MySQL 已启动，然后进入数据库：

```bash
brew services start mysql
mysql -u finals -p finals_compass
```

开发环境密码由 `DB_PASSWORD` 环境变量提供；公开仓库不包含真实密码。

### 添加课程

`slug` 是网址中使用的英文唯一标识，只使用小写字母、数字和短横线，并且创建后尽量不要修改。

```sql
INSERT INTO course (slug, name, code, category, college)
VALUES ('operating-system', '操作系统', 'CS302', '计算机基础', '计算机学院');
```

### 添加老师

```sql
INSERT INTO teacher (slug, name, college)
VALUES ('wang', '王老师', '计算机学院');
```

### 把老师关联到课程

课程和老师创建后，还必须建立关联，否则课程页不会显示这位老师：

```sql
INSERT INTO teacher_course (teacher_id, course_id, term, review_note)
SELECT t.id, c.id, '2026—2027 学年第 1 学期',
       '同学共建页面，具体考试范围以课堂通知为准。'
FROM teacher t
JOIN course c ON c.slug = 'operating-system'
WHERE t.slug = 'wang';
```

刷新浏览器即可看到新数据。开发服务器通常无需重启。

### 修改课程或老师名字

```sql
UPDATE course SET name = '操作系统原理', code = 'CS302'
WHERE slug = 'operating-system';

UPDATE teacher SET name = '王老师', college = '计算机学院'
WHERE slug = 'wang';
```

课程暂时下线时建议使用软删除，以保留已有资料和讨论：

```sql
UPDATE course SET active = FALSE WHERE slug = 'operating-system';
```

### 将数据变更保存进项目

直接执行 SQL 只会改变当前电脑的数据库。若希望其他开发者安装项目后也自动获得这些基础数据，请在下面目录新建一个 Flyway 迁移文件：

```text
services/api/src/main/resources/db/migration/
```

例如：

```text
V16__add_operating_system.sql
```

把上面的 `INSERT` 写入该文件，再启动 Java 后端，Flyway 会自动执行。V1–V15 是已经发布的迁移，不要修改，也不要重复使用相同版本号。

## 4. 前端接口在哪里

前端对 Java 接口的封装集中在：

```text
apps/web/src/api.js
```

- `catalogApi`：课程和老师列表；
- `circleApi`：资料、讨论和上传；
- `initIdentity`：生成并缓存匿名昵称。

本地开发时，`vite.config.js` 会把 `/api` 转发到 `http://localhost:8080`。部署时可以通过 `VITE_API_BASE` 修改 API 地址。

调用接口的主要页面：

- `apps/web/src/views/HomeView.vue`：读取课程列表；
- `apps/web/src/views/TeachersView.vue`：读取某门课程下的老师；
- `apps/web/src/views/TeacherCircleView.vue`：读取和提交老师圈内容。

## 5. Java 后端接口

Java API 默认地址为 `http://localhost:8080/api`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `POST` | `/api/identity/anonymous` | 创建匿名身份 |
| `POST` | `/api/auth/login` | 使用内测账号登录 |
| `POST` | `/api/auth/register` | 封闭内测提示，不创建账号 |
| `POST` | `/api/auth/change-password` | 修改当前账户密码 |
| `POST` | `/api/auth/logout` | 注销当前会话 |
| `GET` | `/api/courses` | 获取启用中的课程 |
| `POST` | `/api/courses` | 管理员添加课程 |
| `GET` | `/api/courses/{courseSlug}/teachers` | 获取课程下的老师 |
| `POST` | `/api/courses/{courseSlug}/teachers` | 添加老师并关联当前课程 |
| `GET` | `/api/circles/{courseSlug}/{teacherSlug}/resources` | 获取老师圈资料 |
| `POST` | `/api/circles/{courseSlug}/{teacherSlug}/resources` | 上传资料，使用 multipart 表单 |
| `GET` | `/api/circles/{courseSlug}/{teacherSlug}/discussions` | 获取讨论 |
| `POST` | `/api/circles/{courseSlug}/{teacherSlug}/discussions` | 发布讨论或回复 |
| `GET` | `/api/circles/{courseSlug}/{teacherSlug}/summary` | 获取老师圈汇总数字 |

对应代码位置：

- `services/api/src/main/java/cn/finalscompass/controller/IdentityController.java`
- `services/api/src/main/java/cn/finalscompass/controller/AuthController.java`
- `services/api/src/main/java/cn/finalscompass/controller/CatalogController.java`
- `services/api/src/main/java/cn/finalscompass/controller/CircleController.java`
- `services/api/src/main/java/cn/finalscompass/model/ApiModels.java`
- `services/api/src/main/resources/application.yml`：数据库、端口和上传目录配置。

修改或新增接口时，通常需要同时修改 Java Controller、`ApiModels.java`、前端 `apps/web/src/api.js`，以及真正使用接口的 Vue 页面。

## 6. 系统指标接口

早期文档规划过独立 Python 分析服务，但该服务没有接入主页面，项目中也已没有可运行的 `analytics/app.py`。当前后台汇总指标统一由 Spring Boot 的 `GET /api/system/metrics` 提供，代码位于 `SystemController.java`，并要求管理员登录。

## 7. 推荐的日常维护顺序

1. 在 MySQL 中新增课程、老师及两者关联。
2. 用浏览器确认课程页和老师页显示正确。
3. 确认无误后，把相同 SQL 写进新的 Flyway 迁移文件。
4. 若接口字段发生变化，同步更新 `apps/web/src/api.js` 和对应 Vue 页面。
5. 执行 `npm run build`，再完整点击检查“课程 → 老师 → 老师圈”。
