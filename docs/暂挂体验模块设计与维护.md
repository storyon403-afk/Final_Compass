# 暂挂体验模块设计与维护

## 产品约定

- 暂挂是用户主动触发的全站体验，不会退出登录、刷新路由或清空表单。
- 推荐视频长度为 8–15 秒，允许范围为 1–30 秒，且播放时始终提供“跳过”。
- 管理员可以关闭全站入口、固定播放某个视频，或从已上传视频中随机播放。
- 没有上传视频、固定视频失效或动态视频载入失败时，前端使用内置默认视频兜底。

## 模块边界

- `apps/web/src/components/SuspendRest.vue`：用户侧状态机（确认、视频、低亮、恢复），不负责管理数据。
- `apps/web/src/components/AdminSuspendModal.vue`：管理员配置和上传界面。
- `apps/web/src/suspendApi.js`：暂挂模块唯一的前端 API 边界，避免继续扩大公共 `api.js`。
- `SuspendController`：后端配置、上传和读取接口。
- `V16__suspend_experience.sql`：独立数据表，不修改现有业务表。
- `${UPLOAD_DIR}/suspend`：动态视频持久化目录；数据库不保存大文件本体。

`App.vue` 只负责挂载用户组件和管理员弹窗。以后合并其他业务分支时，暂挂模块内部通常不会与课程、CET、论坛或 AI 模块产生文件冲突。

## 数据设计

`suspend_setting` 是 ID 固定为 1 的单行配置表，保存启停、`FIXED/RANDOM` 策略和固定视频 ID。`suspend_video` 保存文件名、存储名、MIME 类型、大小、时长及上传管理员。

视频文件位于 Docker 的 `uploads` 持久卷，重新构建前后端镜像不会删除。服务器备份时需要同时备份 MySQL 和 uploads 卷。

## 部署注意

- Spring 上传上限默认 40 MB，请保持 Nginx `client_max_body_size` 不低于 42 MB。
- MP4 的 H.264/AAC 组合浏览器兼容性最好；也支持 WebM。
- 30 秒是管理上限而非推荐长度。视频越长，移动网络流量和用户等待感越明显。
